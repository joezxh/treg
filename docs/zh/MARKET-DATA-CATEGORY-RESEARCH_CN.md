# 市场数据 —— 供应商研究，测试前的审阅

**状态：**仅研究。什么都没加，什么都没测。

一个用户要了市场数据，而且他说得对：它确实缺：40 家供应商横跨 SEO（9）、广告（10）、社交媒体（10）、画像补全（10）和社区（1），而**没有一家金融供应商**。

---

## 先读这个：这个分类的定价方式和我们的其他分类不同

每一个现有的 treg 供应商都是**按 credit 计价**的。Hunter 卖 2,000 credit 换 $49，一个端点声明它花多少 credit，然后 `fx.yaml` 把它变成每次调用的美元数。目录正是这样产出诚实的每次调用价格。

**市场数据几乎普遍不是这样工作的。** 它是作为一个固定月费加上一个**速率限制**来卖的，而在此之内是无限调用：

| 供应商 | 入门方案 | 钱买到了什么 |
|---|---|---|
| Alpha Vantage | $49.99/月 | 每分钟 75 次请求，无每日上限 |
| Twelve Data | $29/月 | 55 credit/分，**每日无限** |
| Polygon（现 Massive） | $29/月 | 无限调用，按资产类别 |
| Finnhub | ~$12–100/月 | 速率限制，固定费 |
| FMP | $15/月 | 固定费 |
| Marketstack | $9.99/月 | 固定费 |
| EODHD | $19.99/月 | 固定费 |
| Tiingo | $30/月 | 固定费 |

没有"包含 N credit"的数字去除以，所以**方案价格 ÷ credit 是未定义的**。这正好就是"$10/月无限"的情形，它迫使我们去做一个之前从不需要做的决定。

### 三个选项，以及各自的成本

**A. 定价为 $0（`type: free`）。** 一旦 treg 付了月费，再多一次调用的边际成本真的为零，所以这是*诚实*的。它也意味着 treg 吸收了订阅，没有每次调用的回收 —— 在 0% 毛利下那是一笔固定的月度开支，上面这些供应商合理地铺开大约 **$150–250/月**。

**B. 摊销：把月费除以预期调用次数。** 产出一个每次调用的数字，但它是预测，不是价格。把量猜错了，每次调用都定错价。这也会是目录里第一个无法追溯到供应商自己费率卡的数字，这破坏了那条让定价站得住脚的规则。

**C. 留它们不定价，只走自有密钥。** 它们加入那 55 个：可用用户自己的 key 调用，绝不走 treg 的。零成本，而且这个分类仍有真实价值 —— 但头条特性（"不需要你自己的 key"）将不适用于它。

**我的判断：**对贵的那些从 **C** 开始，对一两家便宜、高价值的供应商用 **A**，这样分类就存在了，而且里面确实有真正无密钥的东西。直接全面上 A 会把一个免费的目录变成一笔没有回收的月度账单。

唯一干净的例子在下面。

## 短名单

按它们多适合 treg 排序，而不是按数据多好。

### 第一档 —— 干净契合模型

**1. CoinGecko**（加密）—— *我找到的唯一真正按 credit 计价的*
- **$35/月 ÷ 100,000 credit = $0.00035/credit。** 真实的费率卡，像 Hunter 一样整除。
- 认证：`x-cg-pro-api-key` 头，或 query。头，所以我们的注入器能处理它。
- 免费 demo 层（10k credit/月）用于探测。
- 填补加密，目录里没有任何东西触及它。

### 第二档 —— 强数据，固定费定价（需要 A/B/C 决定）

**2. Polygon / Massive** —— 美股、期权、外汇、加密；tick 级。$29/月 Starter。认证：`Authorization: Bearer` **或** `?apiKey=`。免费层 5 次/分、延迟 15 分钟 —— 够探测。这一组里最强的数据。注意 2026 年重命名为 Massive；域名搬了。

**3. Finnhub** —— 实时报价、公司基本面、新闻情绪、另类数据。免费层最慷慨（60 次/分）。认证：`X-Finnhub-Token` 头或 `?token=`。免费层是非商业的，我们在用 treg 的 key 服务它之前必须仔细读。

**4. Twelve Data** —— 股票、外汇、加密，每天 800 次免费调用。认证 `?apikey=`。用了"credits"这个词但按分钟卖，不是按池子，所以它仍是固定费。

**5. Alpha Vantage** —— 200,000+ 标的、20+ 交易所、悠久历史，外加经济指标。免费层每天 25 次请求。认证 `?apikey=`。最便宜的付费层是 $49.99，这里最贵。

**6. Financial Modeling Prep** —— 基本面、报表、比率，每天 250 次免费调用，$15/月 Starter。认证 `?apikey=`。和那些以报价为中心的有所不同：这是基本面的缺口。

**7. EODHD** —— 全球交易所的盘后和历史，$19.99/月。认证 `?api_token=`。填补*全球 + 历史*，那些美国中心的没有。

**8. Marketstack** —— 最便宜，$9.99/月，全球股价，简单。认证 `?access_key=`。如果我们确实挑一个用 treg 的 key 服务，它是一个好的低成本候选。

**9. Tiingo** —— 股票、新闻、基本面、30+ 年历史。$30/月。认证 `Authorization: Token <key>` 头。免费层限制为每月 500 个符号。

### 第三档 —— 值得为覆盖面加上，需要核对

**10. 一个 filings / macro 来源** —— SEC filings（sec-api.io）或经济数据（FRED，带 key 免费）。两者我都未核对定价或认证，所以我列出的是缺口，而不是假装已经挑了一个。

## 状态更新（2026-08-14）：加了八个，去掉一个

第一档和第二档全部走了快速通道，带 LIVE 的垃圾 key 验证：coingecko、polygon、finnhub、twelvedata、fmp、eodhd、marketstack、tiingo 都登记在新的"Market data"货架上，每个条目记录它已验证的坏 key 行为。途中发现并躲开了两个陷阱：CoinGecko 的 demo host 和 Tiingo 的 /api/test 都给垃圾请求回 200，所以两个条目都固定到真正会拒绝的那个路径。

**Alpha Vantage 移到下面的拒绝里。** connect 条目不可能存在：API 给一个垃圾 key 也提供真实报价数据，而且就连 premium 端点也回 200 带一句推销，所以一个粘来的 key 永远无法被验证（ScrapeCreators 规则）。它在 fx.yaml 里的共享方案试点费率仍然有效 —— 平台层服务用的是我们自己订阅的 key，那不需要 connect 验证。

## 已拒绝，含理由

- **Alpha Vantage** —— 接受任何 key（2026-08-14 live 验证：`apikey=bogus123` 返回了 IBM 报价）。一个 key 无法被检查的 key 供应商不能被发布。

- **Yahoo Finance** —— 没有官方 API。每个封装都是非官方的，而且之前被搞坏过或受到法律压力。和 Proxycurl 同一类风险，指南说见到就拒绝。
- **Intrinio** —— 企业销售门槛，没有自助 key。破坏快速通道。
- **IEX Cloud** —— 2024 年关停。死了。
- **Bloomberg / Refinitiv** —— 终端许可，不是任何人能自服务的 API。

## 我还没有验证的，以及加任何一个之前会去验证的

指南说得很清楚：承重的一步是看一个供应商**拒绝一个垃圾 key**，而且 `base_url`、探测路径、坏 key 行为必须 live 确认，而不是假设。

对上面每个供应商，我都有定价和*文档记载*的认证位置。我**还没**确认：

1. **坏 key 行为。** 几个金融 API 对无效 key 返回 `200` 带一个空载荷或 `{"Error Message": …}` body，而不是 401。那是 Apollo/Majestic 陷阱，而且它需要 `token_verify_field` 而不是状态检查。**Alpha Vantage 在此是已知的惯犯** —— 它通常回 200 带一句说明。
2. **每个供应商的一个免费探测端点**，合法 key 通过、无效 key 失败。
3. **免费层的条款是否允许通过 treg 服务它** —— Finnhub 的免费层明确是非商业的，如果用的是 treg 的 key，这就很重要。

这些都不是研究；那是 live 测试，而且是你选好之后的下一步。
