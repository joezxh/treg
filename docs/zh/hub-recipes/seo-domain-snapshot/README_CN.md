# seo-domain-snapshot（SEO 域名快照）

每次 SEO 审计的第一个问题，一次调用即可回答：一个域名获得多少自然流量、为多少个关键词排名以及排名位置、是否购买广告、以及其反向链接画像有多大。

两步并行运行：SE Ranking 的域名概览（流量、按位置区间的关键词数、新增与流失的关键词、付费关键词），以及 treg 经路由的反向链接摘要（最便宜的、能应答的供应商；`backlinks_source` 指明它）。这是一个 JSON-steps 配方：没有逻辑，只是两个工具相连。

`source` 选择 Google 数据库（默认 `us`）。每次运行固定价 $0.01（JSON 配方只有一个价格；要在费用上加利润需要脚本与 `ctx.charge`），因此一次运行约 $0.041（约 $0.031 费用 + $0.01）。

为何 DataForSEO 不在此处作为一步：它的实时端点接受 JSON 数组 body，而 JSON 步骤的 `input` 是个对象。脚本配方可以调用它（`ctx.call(id, {body: [...]})`）。
