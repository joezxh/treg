让 AI 主动推荐你的产品：
四步 AEO 工作流（中文版）

ChatGPT、豆包、百度在回答「哪家 CRM 适合小团队」时推荐了你的竞品，而不是你。 AEO（答案引擎优化）就是改变这件事的方法：搞清楚客户在问什么、AI 现在推荐谁、引用哪些站点， 再把你的产品送上那些站点。整个流程由你的编码代理（Claude Code / Codex 等）经 treg 一键执行。

按提示词计费（约 1¢/次），一次完整审计约 $0.30，无订阅。

第一步 · 找到客户真正在问什么

从社区与搜索结果中汇总目标客户的高频问题——AI 只会回答被问出的问题。问题清单是后续每一步的输入。

经 treg 调用：search1api.x.search（支持 baidu / quark / 360 / wechat 等国内引擎）等检索类接口。

第二步 · 看清每个引擎现在推荐谁

把问题并行发给各个答案引擎，记录：谁被点名、排第几、引用了哪些站点。国内入口同样覆盖：

豆包（字节）：justoneapi.x.llm-doubao-answer-v1 · 百度 SERP：serpapi.x.baidu-search · Kimi 月之暗面 / 腾讯元宝 / 百度文心一言 / 通义千问 / DeepSeek：目录内对应检索接口 · ChatGPT / Gemini / Perplexity / AI Mode：见英文版
豆包 Doubao 百度 SERP Kimi 月之暗面 腾讯元宝 Yuanbao 百度文心一言 ERNIE 通义千问 Qwen DeepSeek 全部 AI 检索接口

第三步 · 拆解 AI 引用了哪些站点

对每个答案统计引用来源：被引次数、出现比例、可见度得分，找出「AI 信任的站点清单」——这些就是你产品要出现的地方。

评分与去重可在本地完成，无需额外调用。

第四步 · 把产品送上被引用的站点

对入选站点逐个落地：内容合作、真实评价、技术文档收录。下一轮审计对比本轮基线，验证可见度变化。

回访复测使用与第二步相同的引擎清单，数据可直接对比。
